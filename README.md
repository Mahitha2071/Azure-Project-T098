# Azure Project – T098

## Azure Resource Decommissioning

### Abstract
This project focuses on the systematic identification, evaluation, and decommissioning of Azure resources to improve cloud resource management, reduce unnecessary costs, and maintain security.

### Objectives
- Identify unused Azure resources.
- Analyze resource dependencies.
- Review resource locks and security.
- Estimate Azure resource costs.
- Plan safe resource decommissioning.

### Technologies Used
- Microsoft Azure
- Azure Resource Graph
- Azure Storage Lifecycle Management
- Azure Pricing Calculator
- Azure Resource Locks

### Project Documentation
This repository contains the project report, presentation, screenshots, and supporting diagrams.

### Conclusion
The project demonstrates the importance of proper Azure resource management, cost optimization, and safe decommissioning practices.
